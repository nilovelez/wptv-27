					<description><![CDATA[En este vídeo mostramos el proceso de trabajo realizado durante nuestras prácticas en WordPress España. El proyecto consiste en diseñar un sistema de recursos visuales para comunidades y meetups, con el objetivo de mejorar la coherencia gráfica de sus comunicaciones y facilitar la creación de piezas para redes sociales, eventos y presentaciones.

Durante el vídeo se puede ver cómo partimos de una fase de investigación, en la que analizamos las necesidades principales: falta de coherencia visual, una paleta de color poco definida y la necesidad de crear una identidad adaptable a distintos formatos. A partir de ahí, desarrollamos en Figma diferentes plantillas y propuestas visuales pensadas para que puedan editarse posteriormente en Canva de forma sencilla.

También se muestran dos líneas gráficas distintas: una más limpia y minimalista, y otra más dinámica y llamativa. Ambas mantienen la identidad de WordPress España, pero ofrecen diferentes posibilidades según el tipo de comunicación o evento. En conjunto, el vídeo resume la evolución del proyecto desde el análisis inicial hasta la creación de un sistema visual flexible, útil y accesible para las comunidades.]]></description>
