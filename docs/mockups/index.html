WordPress.tv design mockups

Static mockups of wptv-27, the new block theme for WordPress.tv, in the visual language of the current WordPress.org sites.

These pages are design references, not the live site. Videos, speakers, events and comments are copied from public WordPress.tv content; links inside the mockups only move between these pages.

  • Front page →

    Hero with the latest video, featured videos, recent videos, categories, recent events and the Get involved band.

  • Single video →

    Video page with the player on a full-width dark band, video details, comments and previous/next links.
